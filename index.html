広島 / 情報共有と業務の仕組みづくり

無料・低コストのツールを組み合わせて、民泊やタクシーの現場の情報共有を整える仕組みを試作しています。物流や管理部門の現場、業務自動化(RPA)の経験をもとに、生成AIと組み合わせて、現場で使われる仕組みづくりに取り組みたいと考えています。

民泊管理デモ

民泊の運営代行を想定したデモ / 広島市中区のマンションの一室(架空)

民泊の運営では、宿泊者からの問い合わせ、清掃の進み具合、オーナーへの報告が、電話やメッセージに散らばりがちです。宿泊者・管理者・清掃スタッフの3つの画面を、一つの仕組みにつなげました。

  • Astro
  • React
  • TypeScript
  • Supabase
  • Cloudflare Pages
  • PWA
宿泊者ガイドを開く 管理画面を開く 清掃スタッフ用アプリを開く GitHubで見る

機能と技術の詳細を見る詳細を閉じる

できること

  • 宿泊者ガイド:QRコードで開き、日本語と英語を切り替えられる
  • 管理画面:物件の案内を編集すると、ガイドにすぐ反映される
  • 清掃スタッフ用アプリ:チェックリスト、写真、完了報告。電波が弱くても入力途中を保存
  • 閲覧専用のデモアカウントで、管理画面も実際に触れる

技術と選んだ理由

  • Astro:文章中心の宿泊者ガイドを、通信の弱い環境でも速く開けるように
  • React、TypeScript、PWA:管理画面と清掃スタッフ用アプリを、スマホにインストールして使えるように
  • Supabase:立場ごとに見られる範囲を、行単位の権限で分けるために
  • Cloudflare Pages:無料枠で公開し、鍵が必要な処理を画面から切り離すために

画面はすべて架空のデータです。非公開のため、画面の紹介のみです

社内ポータル

タクシー会社向けの試作版(POC)

お知らせは掲示板の張り紙、現場の知恵は口頭やLINEと、情報が散らばって全員に届かない。そんな職場に向けて、スマホで使える無料の社内ポータルを作りました。

  • React
  • TypeScript
  • Supabase
  • Cloudflare Pages / Functions
機能と設計の詳細を見る詳細を閉じる

できること

  • 対象者を選んで出せるお知らせと、重要なお知らせの未読確認
  • 乗り場の待ち状況を、乗務員どうしで報告し合う画面
  • 誰でも書けて、すぐ共有できる「知恵袋」
  • イベント情報のカレンダー表示と地図表示
  • 権限ごとに任せる管理画面を選べる仕組み

設計で工夫したこと

  • 社員の氏名を登録しない設計にして、情報流出のリスクを抑えた
  • 乗務員がLINEでうまく回しているやり取りは妨げず、届いていない人に届ける役割に絞った
  • 写真で撮った張り紙は、生成AIで書き起こして人が確認してから載せる運用にした

経歴Career

店舗、営業、物流、管理部門の現場を経て、業務の自動化へ。いまは現場の情報共有の仕組みづくりに取り組みたいと考えています。

2000年〜2019年

店舗・海外営業・物流・管理部門

店長として店舗運営とスタッフ管理を経験したのち、水産系商社の韓国現地法人で、法人営業、物流部門(6名)のマネジメント、購買、業績管理を担当。その後は輸入卸、Webマーケティング、物流などの企業で経理・財務・法務・総務を担い、投資助言会社では監査役として管理体制を立て直しました。どの職場でも、手順書やチェックリスト、タスク管理表を整えて、業務を回る仕組みにすることを続けてきました。

2019年6月〜2020年1月

WinActorによる物流・受発注業務の自動化

飲料メーカーで、1人体制でRPAによる業務の自動化を担当。現場へのヒアリングで自動化する業務を見きわめ、業務フローの提案から、シナリオの設計・開発・テスト・運用・改修までを一貫して行いました。25〜30本のシナリオを作成し、6業務・15シナリオが本番で稼働。早いものは1日で開発し、1週間で運用を開始しました。社内担当者が自分で直せるよう、内製化の支援と手順書の整備も行いました。

2020年4月

PythonによるRPA自動化ファイルの開発支援

不動産事業グループのシステム会社で、2人体制でグループ内業務の自動化ファイルを開発。2ファイルの開発を完了し、OCR関連の作業も補助しました。

2026年

社内ポータル(タクシー会社向けPOC)

現場の情報共有の課題を、無料のツールで解決できるかを検証するために作成しました。
